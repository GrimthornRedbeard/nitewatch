## Findings

### 1. GitHub Actions workflow was enabled and burning paid minutes (policy violation) — remediated

`.github/workflows/agent.yml` triggers on every push/PR and had **3 completed
runs on 2026-07-25** (~2m40s each, ubuntu-latest). Org policy is
no-GitHub-Actions (cost); every other portfolio repo had its CI workflows
disabled 2026-06-14. NiteWatch was created after that sweep and slipped through.

**Remediation taken during this sweep:** `gh workflow disable agent.yml` —
state is now `disabled_manually`, so pushes no longer trigger runs. The
workflow file itself is left in place (it doubles as documentation of the local
verification recipe). Follow-up tracked in an issue: decide keep-disabled vs
delete; if kept, fix the `go-version: '1.22'` vs `go.mod go 1.25.0` drift.

### 2. Reachable stdlib vulnerabilities — toolchain patch-update needed

govulncheck reports **20 vulnerabilities reachable from this code, all in the
Go standard library** (crypto/tls, crypto/x509, net/http, net/url, os,
encoding/asn1, encoding/pem), entering almost entirely via
`http.Server.ListenAndServe` in `agent/internal/api/server.go`. The dev
toolchain is **go1.25.0**; every finding is fixed by **go1.25.12** or earlier
patch releases. No third-party module vulns are reachable (8 exist in imports
but are not called).

Severity context: the server binds loopback-only, so the practical exposure is
local processes — but this is a security product; ship on a patched toolchain.
**Action:** update Go to the latest 1.25.x on the dev box, add a
`toolchain go1.25.12` (or newer) directive to `agent/go.mod`, rebuild, re-run
govulncheck. Tracked in an issue.

### 3. Build/runtime artifacts committed to git

- `agent/nitewatch` — a **2.3 MB unstripped Linux ELF** build output, tracked.
  `.gitignore` covers `*.exe` but not the extensionless Linux binary.
- `agent/nitewatch.log` — a runtime log file, tracked (main.go appends to it on
  every dev-box run, so it will show as perpetually dirty).
- `agent/dist/run-nitewatch.bat` and `agent/scripts/run-nitewatch.bat` are
  byte-identical duplicates; `dist/` is a build-output dir and should be
  ignored, keeping `scripts/` as the source of truth.

**Action:** `git rm --cached` the binary and log, ignore `agent/nitewatch`,
`*.log`, and `agent/dist/`. Tracked in an issue.

### 4. gofmt drift (trivial)

`agent/internal/event/event.go` has one line of comment-alignment drift on the
`Seq` field. `gofmt -w` fixes it. Folded into the hygiene issue.
